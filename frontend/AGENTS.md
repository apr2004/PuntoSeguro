# Frontend de PuntoSeguro

Aplicación web React con Vite. Mantén separados componentes, páginas, hooks y acceso a la API según se necesiten. Comprueba el contrato del backend al integrar llamadas y ejecuta `npm run build` desde `frontend/`.

La skill copiada de UrbanPulse en `frontend/.agents/` describe Expo y React Native; adapta sus indicaciones al stack web de este proyecto.
